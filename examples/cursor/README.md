# Cursor — install via MCP

Copy `mcp.json` in this directory to `~/.cursor/mcp.json` (or merge into the existing file). Restart Cursor.

The 4 tools (`searchEvents`, `getVenueInfo`, `planOuting`, `recommendEvents`) appear in Cursor's MCP tool list. Use them in chat:

> *"Use israeli-events to find concerts in Haifa this month under 200 NIS"*

## Verify

`Cmd/Ctrl-Shift-P` → "MCP: List Servers" → look for `israeli-events`.
